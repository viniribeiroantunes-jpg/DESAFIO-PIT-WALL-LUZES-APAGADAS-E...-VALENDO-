# 🏎️ PITWALL — GP DE SÃO PAULO

Projeto desenvolvido como atividade prática do curso de Desenvolvimento de Sistemas, utilizando HTML5 e CSS3.

## 📌 Sobre o projeto

O objetivo é recriar uma página inspirada no Grande Prêmio de São Paulo de Fórmula 1, realizado no Autódromo de Interlagos.

A página apresenta informações sobre pilotos, equipes, classificação e ingressos.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- Flexbox
- CSS Grid
- Media Queries

## 📂 Estrutura do projeto

```text
pit-wall/
├── index.html
├── styles.css
├── README.md
└── img/
    └── piloto.jpg
```

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em computadores e dispositivos celulares, utilizando Media Queries para adaptar o layout.
